## Featured Projects

### Raquette

AI tennis rally analysis that turns broadcast footage into structured data with ball and player tracking, bounce calls, shot classification, and a top-down court map.

[Live Demo](https://raquette.vercel.app) · [GitHub](https://github.com/LightAnd2/Raquette)

### LightAPI

A directory of more than 1,500 public APIs with real-time uptime monitoring, latency tracking, WebSocket updates, and per-endpoint anomaly detection.

[Live Site](https://lightapi.dev) · [GitHub](https://github.com/LightAnd2/LightAPI)

### FootyLive

A full-stack football dashboard with live scores, standings, fixtures, knockout brackets, and archived seasons across 12 competitions.

[GitHub](https://github.com/LightAnd2/FootyLive)

### CrimeScope

An interactive crime-data visualization that normalizes live incident records from 17 U.S. city portals into pin, cluster, and heatmap views.

[Live Site](https://crime-scope.vercel.app) · [GitHub](https://github.com/LightAnd2/CrimeScope)

## Run Locally

This is a static website, so no dependency installation or build step is required.

```powershell
python -m http.server 4173
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).
